## Abstract

Transformer-based models such as BERT have dramatically improved performance for various NLP tasks. ClinicalBERT achieved state-of-the-art results on clinical NER and NLI tasks. However, a core limitation of these transformers is substantial memory consumption due to their full self-attention mechanism. Long sequence transformers (Longformer, BigBird) use sparse attention to reduce memory usage from quadratic to linear in sequence length, extending maximum input from 512 to 4,096 tokens. Inspired by these, the authors introduce Clinical-Longformer and Clinical-BigBird, pre-trained on large-scale clinical corpora. Evaluated on 10 baseline tasks (NER, QA, document classification), both models consistently and significantly outperform ClinicalBERT and other short-sequence transformers across all downstream tasks.

## Problem Statement

Transformer-based models like BERT are limited to 512-token input sequences due to quadratic memory scaling of full self-attention. This is problematic for clinical NLP because clinical documents are typically much longer:

- MIMIC-III discharge summaries average 1,435 words -- far exceeding the 512-token limit
- i2b2 2014 NER data has average sequence length of 5,134 tokens (max 14,370)
- emrQA Heart Disease subset averages 5,293 tokens (max 14,060)

Current workarounds (truncation to 512 tokens or segmentation into chunks with aggregation) lose long-term dependencies and yield suboptimal results. While general-domain long-sequence transformers exist (Longformer, BigBird), their adaptability to clinical and biomedical text had been rarely investigated.

## Key Contributions

1. **Pre-trained and publicly released** two transformer models for long clinical sequences: Clinical-Longformer and Clinical-BigBird, using large-scale clinical notes from MIMIC-III.
2. **Demonstrated consistent and significant improvements** over ClinicalBERT, BioBERT, and BERT across all 10 downstream clinical NLP tasks spanning question answering, named entity recognition, natural language inference, and document classification.
3. **Showed that long-context pre-training benefits even short-sequence tasks** -- improvements were observed on MedNLI (max 409 tokens) and OpenI (max 294 tokens), which fit entirely within BERT's 512-token limit.
4. **Provided comprehensive benchmarking** across heterogeneous clinical NLP tasks, going beyond prior work (Levine et al.) that only evaluated on document classification/ICD coding.

## Methodology/Architecture

### Pre-training Corpus
- ~2 million clinical notes from MIMIC-III (largest publicly available EHR dataset)
- Contains clinical narratives of >40,000 ICU patients
- Minimal preprocessing: removed de-identification placeholders, non-alphanumeric characters, converted to lowercase, stripped extra whitespace

### Model Architecture
Both models use **sparse attention mechanisms** that reduce memory complexity from O(n^2) to O(n):

| Feature | Longformer | BigBird |
|---------|-----------|---------|
| Attention type | Sliding window + global attention | Sliding window + global attention + random attention |
| Max sequence length | 4,096 tokens | 4,096 tokens |
| Memory scaling | Linear | Linear |
| Initialization | Base Longformer weights | ITC BigBird weights |

### Pre-training Details

| Parameter | Clinical-Longformer | Clinical-BigBird |
|-----------|-------------------|-----------------|
| Training steps | 200,000 | 300,000 |
| Batch size | 6 x 3 = 18 | 6 x 2 = 12 |
| Learning rate | 3e-5 | 3e-5 |
| Hardware | 6 x 32GB Tesla V100 GPUs | 6 x 32GB Tesla V100 GPUs |
| Precision | FP16 | FP16 |
| Training time | >2 weeks | >2 weeks |
| Tokenization | Byte-level BPE | Byte-level BPE |
| Pre-training task | Masked Language Modeling | Masked Language Modeling |

### Fine-tuning Setup
- Token-level tasks (QA, NER): max sequence length 3,072 for long models, 384 for baselines
- Sequence-level tasks (classification): [CLS] token output; short models use 512-token segments with pooling aggregation
- All documents first truncated to 4,096 tokens
- Learning rates tested: 1e-5, 2e-5, 5e-5
- 6 epochs per setup; best model selected on dev split
- Implementation: Python 3.8.0, PyTorch 1.9.0, Transformers 4.9.0

### Baseline Models
- **BERT:** Pre-trained on BooksCorpus + English Wikipedia (512 tokens)
- **BioBERT:** Initialized from BERT, further pre-trained on PubMed abstracts + PMC full-text (512 tokens)
- **ClinicalBERT:** Initialized from BioBERT, further pre-trained on MIMIC-III clinical notes (512 tokens)

## Results

### Question Answering (emrQA)

| Model | Medication EM | Medication F1 | Relation EM | Relation F1 | Heart Disease EM | Heart Disease F1 |
|-------|-------------|-------------|-----------|-----------|----------------|----------------|
| BERT | 0.240 | 0.675 | 0.833 | 0.924 | 0.650 | 0.698 |
| BioBERT | 0.247 | 0.700 | 0.836 | 0.926 | 0.647 | 0.702 |
| ClinicalBERT | 0.297 | 0.698 | 0.849 | 0.929 | 0.666 | 0.711 |
| **Clinical-Longformer** | **0.302** | **0.716** | **0.911** | **0.948** | **0.698** | **0.734** |
| Clinical-BigBird | 0.300 | 0.715 | 0.898 | 0.944 | 0.664 | 0.711 |

### Key Observations
- Clinical-Longformer outperformed all baselines on 9 of 10 tasks (BioBERT slightly better on OHSUMed, a biomedical -- not clinical -- dataset)
- Performance gains were **larger on datasets with longer sequences** (e.g., i2b2 2014 improvement ~2x that of other NER tasks)
- Clinical-Longformer consistently outperformed Clinical-BigBird while requiring less fine-tuning time
- Improvements observed even on short-sequence tasks (MedNLI, OpenI), attributed to better long-term dependency learning during pre-training

## Limitations

1. **Only applied to clinical corpora:** Did not pre-train on biomedical literature (PubMed/PMC), which limits performance on biomedical (non-clinical) tasks like OHSUMed.
2. **No comparison to compressed transformers:** Did not compare against model compression approaches (e.g., TinyBERT) that also address the memory problem.
3. **No text generation/summarization evaluation:** Could not integrate models into encoder-decoder frameworks due to GPU memory limitations.
4. **Single pre-training corpus:** Only used MIMIC-III; other clinical text sources (e.g., outpatient notes, pathology reports) were not included.
5. **4,096-token maximum:** While 8x BERT's limit, some clinical documents still exceed this (e.g., i2b2 2014 max = 14,370 tokens; MIMIC-AKI max = 20,857 tokens).

## Relevance to CTRA

This paper provides a **key backbone model** for the CTRA project:

- **Long-document processing for clinical trial protocols:** Clinical trial protocols are typically several hundred pages long, far exceeding BERT's 512-token limit. Clinical-Longformer's 4,096-token context window is essential for processing protocol sections without losing information through truncation.
- **Clinical domain pre-training:** Clinical-Longformer is pre-trained on clinical notes from MIMIC-III, giving it domain-specific vocabulary and language patterns relevant to clinical trial documentation. This is preferable to general-purpose Longformer for the CTRA task.
- **Proven superiority on clinical NLP tasks:** The consistent improvements over ClinicalBERT across NER, QA, and classification tasks validate Clinical-Longformer as the preferred encoder for clinical text analysis in CTRA.
- **Document classification capability:** The MIMIC-AKI binary classification results (AUC 0.762 vs. ClinicalBERT's 0.738) demonstrate the model's ability to classify clinical documents -- directly relevant to CTRA's binary/ternary classification of protocol uninformativeness risk.
- **Feature extraction for protocols:** The NER capabilities (extracting entities from long clinical text) could be adapted for extracting risk-relevant features from protocol documents (e.g., sample size mentions, statistical analysis plan sections, endpoint definitions).
- **Publicly available model:** The pre-trained model is freely available on HuggingFace, enabling direct integration into the CTRA pipeline without costly pre-training.
