## Abstract

The Upper Confidence Bounds For Trees (UCT) algorithm is not agnostic to the reward scale of the game it is applied to. For zero-sum games with sparse rewards of {-1, 0, 1}, this is not a problem, but many games feature dense rewards with hand-picked reward scales, causing a node's Q-value to span different magnitudes across different games. This paper evaluates various strategies for adaptively choosing the UCT exploration constant lambda (called lambda-strategies) that are agnostic to the game's reward scale. These include strategies from the literature as well as five new strategies. The authors recommend using one of their newly suggested strategies: choosing lambda = 2 * sigma, where sigma is the empirical standard deviation of all state-action pairs' Q-values in the search tree (called "Global Std"). This method outperforms existing strategies across a wide range of tasks both in terms of a single parameter value and peak performances obtained by optimizing all available parameters.

## Problem Statement

1. **UCT is scale-dependent**: The exploration constant lambda in UCT must be manually tuned for each game's reward scale. If lambda is not on the same scale as Q-values, UCT degrades to either uniform random selection (lambda >> |Q|) or greedy selection (lambda << |Q|).
2. **Arbitrary reward scales**: Many practical games and MDPs have dense rewards with arbitrarily chosen scales, making a single fixed lambda inappropriate across domains.
3. **Up to 40% performance loss**: Mismatched exploration constants can cause catastrophic performance degradation, as demonstrated empirically.

## Key Contributions

1. **12 lambda-strategies evaluated**: 5 from literature + 7 newly proposed, systematically compared across 17 MDPs and 11 two-player games.
2. **Global Std recommendation**: lambda = C * sigma_T (where sigma_T is the empirical standard deviation of all Q-values in the search tree) with C=2 is the best-performing strategy, both parameter-optimized and as a single fixed parameter.
3. **40% performance gap**: Vanilla UCT with a single C value shows ~40% lower performance than Global Std with C=2 across diverse environments.
4. **Theoretical analysis**: Scale-invariant strategies are proven to satisfy desirable properties (shift-invariance, scale-invariance, convergence guarantees). Range-based strategies lack convergence guarantees due to sensitivity to outliers.

## Methodology/Architecture

### Lambda-Strategy Framework

Instead of a constant lambda, treat it as a function lambda(T, N, a) of the search tree T, decision node N, and action a. All strategies have the form lambda = C * lambda_hat, where C is a scale-independent parameter.

### Strategies Evaluated

**Global strategies** (use all Q-values in tree):
- **Global Range**: lambda_hat = Q_max^T - Q_min^T (Schrittwieser et al.)
- **Global Abs**: lambda_hat = average absolute Q-value (new)
- **Global Std**: lambda_hat = sigma_T, empirical std dev of all Q-values (new, **recommended**)

**Layer strategies** (use Q-values from same tree depth):
- **Layer Range**, **Layer Abs**, **Layer Std** (all new)

**Local strategies** (use Q-values from current node only):
- **Local Range**, **Local Std** (new), **Local Abs**, **Local Q** (literature)
- **Poly-UCB1** (Gray et al., literature)

**Baseline**: Vanilla UCT with fixed lambda (Kocsis & Szepesvari)

### Desirable Properties

1. Scale-invariance: lambda(c*R) = c * lambda(R)
2. Shift-invariance: lambda(R + b) = lambda(R)
3. Convergence: lambda converges as tree grows (std strategies converge; range strategies do not, due to outlier sensitivity)

## Datasets

- **17 MDPs**: Academic Advising, Cooperative Recon, Crossing Traffic, Earth Observation, Elevators, Game of Life, Manufacturer, Navigation, Push Your Luck, Racetrack, Red Finned Blue Eye, Sailing Wind, Skill Teaching, Saving, SysAdmin, Tamarisk, Traffic, Triangle Tireworld, Wildfire, Wildlife Preserve
- **11 two-player games**: Chess, Constrictor, Connect 4, Numbers Race, Othello, Pentago, Quoridor, ReversiGT, TicTacToe, UltimateTicTacToe, UTTT
- **Iteration budgets**: 100, 1000, 10000 MCTS iterations per move
- **C values tested**: {0.125, 0.25, 0.5, 1, 2, 4, 8, 16, 32, 64} for all strategies, plus {256, 1000} for Vanilla UCT

## Results

- **Global Std (C=2)** achieves the highest normalized pairings score across all environments and iteration budgets, outperforming all other strategies.
- **Global strategies outperform local**: Aggregating Q-values across the entire tree provides better estimates than local-only approaches.
- **40% performance gap**: Vanilla UCT with a single C value is ~40% worse than Global Std with C=2 on average across all environments.
- **Scale-invariant benefits beyond scale adaptation**: Even on two-player zero-sum games (which all share the same {-1, 0, 1} reward scale), Global Std still outperforms Vanilla UCT, suggesting the global Q variance serves as a proxy for uncertainty and required exploration.
- **Convergence advantage**: Std-based strategies converge to stable values as the tree grows; range-based strategies diverge due to outlier sensitivity.

## Limitations

1. **Computational overhead**: Global strategies require tracking the standard deviation of all Q-values in the tree, though this can be done incrementally with O(1) per update.
2. **Game-specific edge cases**: Performance on specific games may vary; the recommendation is based on aggregate performance across a broad benchmark.
3. **Fixed C=2 recommendation**: While C=2 is the best single value, per-game tuning of C could yield further improvements.
4. **No non-game domains tested**: Evaluation focuses on games and MDPs; applicability to other MCTS use cases (e.g., LLM agent tree search) is not directly validated.

## Relevance to CTRA

This paper directly informs CTRA's MCTS exploration parameter tuning, referenced in `README.md` as ref [31]. Key impacts on CTRA:

1. **Exploration constant fix**: The README documents an MCTS fix to "Reduce alpha from 1.0 to ~0.15" — this is informed by this paper's demonstration that mismatched exploration constants cause up to 40% performance loss. CTRA's feature engineering rewards have a non-standard scale (ROC-AUC values), making scale-independent strategies essential.

2. **Global Std as candidate strategy**: The paper's recommended strategy (lambda = 2 * sigma, where sigma is the empirical standard deviation of Q-values) is a candidate for CTRA's adaptive exploration constant. This would replace the current fixed alpha with a data-driven value that automatically adapts to the distribution of feature set evaluation scores.

3. **Convergence guarantees**: The theoretical analysis showing std-based strategies converge while range-based ones diverge supports CTRA's preference for stable search behavior over long rollout budgets.
