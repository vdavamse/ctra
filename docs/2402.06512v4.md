## Abstract

The clinical trial is a pivotal and costly process, often spanning multiple years and requiring substantial financial resources. LIFTED (muLti-modal mIx-of-experts For ouTcome prEDiction) is proposed to address limitations of prior approaches that rely on manually designed modal-specific encoders. LIFTED unifies different modality data by transforming them into natural language descriptions via an LLM, constructs unified noise-resilient encoders to extract information from modal-specific language descriptions, employs a Sparse Mixture-of-Experts (SMoE) framework to identify similar information patterns across different modalities, and uses an MoE module to dynamically integrate different modality representations for prediction. Experiments demonstrate that LIFTED significantly enhances performance across all three clinical trial phases compared to the best baseline.

## Problem Statement

Existing data-driven approaches for clinical trial outcome prediction rely on **manually designed modal-specific encoders** (e.g., HINT uses MPNN for molecules, GRAM for diseases, BERT for criteria). This creates three challenges:

1. **Unified encoding**: Different modalities are in different formats (graphs, hierarchies, text), making a unified encoder difficult.
2. **Cross-modal pattern sharing**: Information across modalities can be presented in both similar and different forms. A method to dynamically identify and extract similar patterns across modalities is needed.
3. **Dynamic modality integration**: The contribution of each modality varies per sample. An approach to automatically weigh modality representations is required.

## Key Contributions

1. **Unified text-based encoding**: All modality data (diseases, criteria, drug names, drug descriptions, SMILES) are converted to natural language descriptions using an LLM, enabling unified transformer-based encoders.
2. **Sparse Mixture-of-Experts (SMoE)**: Routes representations from different modalities to shared expert models, enabling extraction of similar information patterns across modalities via the same expert.
3. **Consistent representation augmentation**: Adds minor perturbations to embeddings with a consistency loss, making encoders and SMoE robust to data noise.
4. **MoE-based multimodal integration**: Treats modality representations as distinct experts and dynamically combines them using learned modality importance weights (primarily conditioned on disease modality).
5. **Auxiliary unimodal prediction loss**: Ensures each modality's representation individually contributes to prediction quality.

## Methodology/Architecture

### Step I: Modality Preprocessing
- Extract 5 modalities: diseases, criteria, drug names, drug descriptions, drug SMILES.
- **Linearization**: Format each data point as key-value pair `{feature_name: value}`.
- **Prompting**: Use an LLM (with prefix describing schema + suffix instructing natural language summary) to generate concise natural language descriptions for each modality.
- **Summarization modality**: Concatenate all modality linearizations to generate an overall trial description (6th modality).

### Step II: Representation Learning and Refinement
- K+1 transformer-based encoders (one per modality, including summarization).
- Each description tokenized, embedded via modal-specific embedding layer, position embeddings added, processed by modal-specific transformer encoder with learnable [cls] token.
- SMILES modality uses a specifically designed tokenizer; all others share a unified tokenizer.

### Sparse Mixture-of-Experts (SMoE)
- Encoded representations from all modalities routed by a **modality-independent noisy top-k gating network** to a subset of R shared expert models.
- Gating: `G(U) = Softmax(TopK(U * Wg + noise * Softplus(U * Wnoise), k))`
- Refined representation: weighted combination of top-k expert outputs.

### Consistent Representation Augmentation
- Randomly perturb embedding elements by `exp(alpha)` where alpha ~ Uniform(-lambda, lambda).
- **Consistency loss**: `L_con = (1/N(K+1)) * sum ||U_tilde - V_tilde||^2_F` (Frobenius norm between original and augmented representations).

### Multimodal Integration (MoE)
- Disease modality representations generate importance weights for all modalities via a fully connected layer with learnable temperature factors.
- Integrated representation: `U_i = sum(W_i,k * U_tilde_i,k)`.
- Classifier predicts outcome from integrated representation.

### Loss Functions
- Classification loss: `L_c` (cross-entropy)
- Auxiliary loss: `L_aux` (sum of unimodal prediction losses)
- Consistency loss: `L_con`
- **Total**: `L = L_c + eta_1 * L_con + eta_2 * L_aux`

### Training Details
- 5 epochs, batch size 32, AdamW optimizer (lr=3e-4, weight decay=1e-2), CosineAnnealing scheduler.
- Single NVIDIA 4090 GPU, up to 2 hours training time.

## Results

### Main Results on HINT Dataset (%, averaged over 30 runs)

| Phase | Method | PR-AUC | F1   | ROC-AUC |
|-------|--------|--------|------|---------|
| I     | HINT   | 58.4   | 68.2 | 62.1    |
| I     | SPOT   | 69.8   | 68.4 | 64.6    |
| I     | **LIFTED** | **70.7** | **71.6** | **64.9** |
| II    | HINT   | 59.1   | 63.9 | 62.8    |
| II    | SPOT   | 62.6   | 64.3 | 63.0    |
| II    | **LIFTED** | **69.8** | **66.2** | **65.1** |
| III   | HINT   | 85.9   | 80.9 | 70.8    |
| III   | MMF(late) | 86.9 | 83.1 | 71.8  |
| III   | **LIFTED** | **88.3** | **83.8** | **73.5** |

LIFTED consistently outperforms all baselines across all three phases on both HINT and CTOD datasets.

### Ablation Studies
- Removing augmentation (LIFTED-aug), auxiliary loss (LIFTED-aux), LLM preprocessing (LIFTED-LLM), or using all modalities for gating (LIFTED-gating) all degrade performance, confirming each component's contribution.
- Disease modality alone is sufficient for generating gating weights.

### Multimodal Integration Analysis
- Criteria and disease modalities are most important; drug description is least important.
- LIFTED with all modalities outperforms any single-modality model.

### SMoE Analysis
- Certain experts (e.g., experts 6 and 7) are shared across modalities, extracting common patterns.
- Other experts specialize in specific modalities.

### Case Study
- For a type 2 diabetes mellitus patient, the model correctly assigns highest weight (34%) to the disease modality, consistent with the disease being hard to cure.

## Limitations

- The paper does not include an explicit limitations section.
- Implicitly: relies on an LLM to generate natural language descriptions (quality depends on LLM capabilities); the SMILES tokenizer is modality-specific (breaking the fully unified encoder goal); evaluation is limited to two benchmarks (HINT, CTOD); the approach requires an LLM preprocessing step that adds computational overhead.

## Relevance to CTRA

LIFTED is relevant to the CTRA project in several ways:

- **Natural language unification**: The idea of converting all modalities (including structured data like ICD codes and SMILES) into natural language descriptions via LLM prompting is a powerful approach that CTRA could adopt for protocol risk features.
- **Mixture-of-Experts for modality weighting**: The dynamic weighting of modalities per sample is directly relevant to CTRA, where different protocol features may be more or less informative depending on the trial context.
- **Noise-resilient encoding**: The representation augmentation and consistency loss could help CTRA handle noisy or incomplete protocol data.
- **Criteria as most important modality**: The finding that eligibility criteria are among the most important modalities reinforces the centrality of protocol text analysis in CTRA's mission.
- **Key distinction**: Like MEXA-CTP, LIFTED predicts drug efficacy outcomes (success/failure), not protocol quality or informativeness. However, the multimodal fusion architecture and the emphasis on criteria text are directly transferable to CTRA's protocol-centric prediction task.
