## Abstract

Many existing models for clinical trial outcome prediction are optimized using task-specific loss functions on trial phase-specific data. While this may boost prediction for common diseases and drugs, it can hinder learning of generalizable representations, leading to more false positives/negatives. CLaDMoP introduces a new pre-training approach for clinical trial outcome prediction, alongside the Successful Clinical Trials dataset (SCT), specifically designed for the pre-training task. CLaDMoP leverages a Large Language Model (BioGPT) to encode eligibility criteria, linked to a lightweight Drug-Molecule (DM) branch through a novel multi-level fusion technique. A grouping block drastically reduces computational overhead when fusing long embeddings across levels. CLaDMoP avoids task-specific objectives by pre-training on a "pair matching" proxy task. After Parameter-Efficient Fine-Tuning (PEFT), CLaDMoP achieves up to 10.5% improvement in PR-AUC and 3.6% in ROC-AUC over MEXA-CTP, while attaining comparable F1 score, on the Trial Outcome Prediction (TOP) benchmark.

## Problem Statement

1. **Task-specific loss functions hinder generalization**: Existing models (HINT, MEXA-CTP) are optimized with task-specific losses on phase-specific data, which limits their ability to generalize to rare/new diseases and increases false positives/negatives.
2. **Heavy reliance on labeled data**: All prior works depend heavily on manually annotated historical data for supervised training.
3. **No pre-training paradigm exists**: Unlike vision-language models (e.g., CLIP), there is no established self-supervised pre-training approach for clinical trial outcome prediction.

## Key Contributions

1. **CLaDMoP**: A new pre-training approach for clinical trial outcome prediction using self-supervised contrastive learning, combined with the **Successful Clinical Trials (SCT) dataset** specifically constructed for this purpose.
2. **Two-branch architecture**: An LLM branch (frozen BioGPT) for eligibility criteria paired with a lightweight Disease-Molecule (DM) branch, with knowledge sharing via **multi-level feature fusion**.
3. **Grouping blocks**: A novel mechanism using cross-attention with trainable centroid tokens to progressively reduce token sequence length, preventing quadratic growth in computational cost during multi-level fusion.
4. **Parameter-Efficient Fine-Tuning (PEFT)**: LoRA layers on the DM branch and a prediction head trained with supervised loss, achieving SOTA results.
5. **Generalization to new diseases**: CLaDMoP outperforms MEXA-CTP by 13.63% (Phase I) and 8.02% (Phase II) in accuracy on disease combinations not seen during training.

## Methodology/Architecture

### Overall Design (CLIP-inspired Two-Branch Architecture)

CLaDMoP follows a two-stage training paradigm:
- **Stage 1 (Pre-training)**: Self-supervised pair matching with task-agnostic loss (InfoNCE).
- **Stage 2 (Fine-tuning)**: Supervised PEFT with class-weighted binary cross-entropy.

### LLM Branch
- **Model**: BioGPT (specialized for biomedical text), with parameters **frozen** during training.
- **Multi-level embeddings**: 24 BioGPT transformer blocks divided into 4 groups of 6 blocks each. Three intermediate embedding levels are extracted:
  - **Coarse**: After blocks 1-6
  - **Medium**: After blocks 7-12
  - **Fine**: After blocks 13-18
- Final layer embedding: `U^C = BioGPT(C)`

### DM (Disease-Molecule) Branch
- **Drug Molecules**: SMILES segments encoded via DeepChem with learnable positional embeddings to distinguish molecules, enriched via self-attention layers.
- **Target Diseases**: ICD-10 codes encoded via `icdcodex` with learnable positional embeddings shared by same-category diseases, enriched via self-attention layers.
- **Architecture**: 4 self-attention layers per block, 8 attention heads, embedding size 16.

### Multi-Level Feature Fusion

**Grouping Layer**: Cross-attention mechanism where trainable centroid tokens (queries) attend to input tokens (keys/values):
```
U^agg = softmax((U^centroid * W^Q * (U * W^K)^T) / sqrt(d_k)) * U * W^V
```
This ensures the output sequence length equals the number of centroids (fixed), regardless of input length. Self-attention layers (S layers) are stacked on top of cross-attention for quality.

**Grouping Block**: G grouping layers stacked, with centroids halved at each layer (e.g., 100 -> 50 -> 25).

The DM branch fuses LLM embeddings in order: coarse, then medium, then fine, with layer normalization on the final output.

### Pre-training Stage
- **Dataset**: Successful Clinical Trials (SCT) -- newly constructed.
- **Proxy task**: Pair matching -- maximize similarity between matching (M, D) and C from successful trials, minimize for non-matching pairs.
- **Loss**: Symmetric InfoNCE loss (cross-entropy over rows and columns of similarity matrix).
- **Training**: Adam optimizer, batch size 128, lr=1e-4, temperature=0.6. LLM branch frozen.

### Fine-tuning Stage (PEFT)
- Average pooling on both branches, concatenation, prediction head (3-layer FFN with ReLU and residual connections) with sigmoid.
- LoRA layers (rank 8) added to all attention layers in DM branch.
- Pre-trained parameters frozen; only prediction head and LoRA layers trained.
- **Loss**: Class-weighted BCE: `L_PEFT = -w0 * y * log(y_hat) - w1 * (1-y) * log(1 - y_hat)`

## Results

### Pre-training Stage (vs. zero-shot and few-shot baselines)
CLaDMoP substantially outperforms ANIL (zero-shot), BioGPT (zero-shot), and MAML (few-shot) across all phases. Performance gaps over MAML are particularly large in Phase I and II (e.g., +23.5% and +184.8% in F1 for Phases I and II, respectively). The pre-trained model even outperforms some supervised baselines without any fine-tuning.

### Ablation Studies (Phase III)

**Grouping Block Configuration**:
- Best: G=3, S=2 (CLaDMoP default). Fewer grouping layers or self-attention layers degrade performance.

**LoRA in Fine-tuning**:
- Best: head + XLoRA + SLoRA (CLaDMoP default). Training both cross-attention and self-attention LoRA layers with the prediction head gives +1.2% F1 and +2.9% ROC-AUC over second-best config.

**Training Strategy**:
- Pre-training + fine-tuning is essential; without either stage, performance drops significantly.
- w/o fine-tuning: F1=.357, PR-AUC=.466, ROC-AUC=.514
- w/o pre-training: F1=.800, PR-AUC=.766, ROC-AUC=.680
- CLaDMoP: F1=.861, PR-AUC=.860, ROC-AUC=.702

**Dataset Usage Strategy**:
- **Full-Split** (pre-train on full SCT, fine-tune on phase-specific TOP) is optimal.
- Pre-training on full SCT yields massive improvements over phase-split SCT (up to 342% F1 improvement in Phase I).

## Limitations

- The paper does not include an explicit limitations section, but implicit limitations include:
- **SCT dataset assumptions**: Assumes drugs on the market successfully passed all phases and that progression to the next phase implies prior phase success. These assumptions may not hold in all cases.
- **BioGPT dependency**: The frozen LLM branch limits adaptability; BioGPT's pretraining data and biases propagate to the model.
- **Single benchmark**: Evaluation is limited to the TOP benchmark (with SCT for pre-training). No cross-benchmark evaluation (e.g., on CTOD).
- **Binary outcome**: Predicts success/failure only, not more nuanced outcomes.
- **LLM challenges acknowledged**: The paper discusses (in Related Work) the risks of hallucinations, societal biases, and regulatory concerns with LLMs in healthcare, though these are not directly mitigated in the approach.

## Relevance to CTRA

CLaDMoP is highly relevant to the CTRA project:

- **Self-supervised pre-training paradigm**: The CLIP-inspired contrastive pre-training on successful trials is a powerful idea for CTRA. A similar approach could be used to pre-train models on "informative" protocols before fine-tuning for uninformativeness prediction. The SCT dataset construction methodology could inspire CTRA-specific dataset creation.
- **LLM-based criteria encoding**: Using BioGPT to encode eligibility criteria and extracting multi-level intermediate embeddings (coarse/medium/fine) provides a sophisticated approach to protocol text representation that CTRA could adopt.
- **Multi-level feature fusion with grouping blocks**: The grouping block mechanism for efficiently fusing long LLM embeddings with lightweight model embeddings is directly applicable to CTRA's need to combine protocol text features with structured trial metadata.
- **Generalization to new diseases**: CLaDMoP's demonstrated ability to generalize to unseen disease combinations is particularly relevant for CTRA, which must handle novel protocols and disease areas.
- **Parameter-efficient fine-tuning**: The LoRA-based PEFT approach allows adaptation with minimal labeled data, which is valuable for CTRA where labeled "uninformative protocol" data may be scarce.
- **Key distinction**: CLaDMoP predicts trial success/failure (drug efficacy), while CTRA predicts protocol uninformativeness. However, the pre-training methodology, LLM integration, and multimodal fusion are directly transferable.
