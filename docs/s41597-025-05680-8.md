## Abstract

Clinical trials are pivotal for developing new medical treatments but typically carry risks such as patient mortality and enrollment failure that waste immense efforts spanning over a decade. Applying artificial intelligence (AI) to predict key events in clinical trials holds great potential for providing insights to guide trial designs. However, complex data collection and question definition requiring medical expertise have hindered the involvement of AI thus far. This paper tackles these challenges by presenting a comprehensive suite of 23 meticulously curated AI-ready datasets covering multi-modal input features and 8 crucial prediction challenges in clinical trial design, encompassing prediction of trial duration, patient dropout rate/event, serious adverse event, mortality event, trial approval outcome, trial failure reason, drug dose, and design of eligibility criteria. Furthermore, we provide basic validation methods for each task to ensure the datasets' usability and reliability. We anticipate that the availability of such open-access datasets will catalyze the development of advanced AI approaches for clinical trial design, ultimately advancing clinical trial research and accelerating medical solution development.

## Problem Statement

Clinical development programs typically span 7--11 years, cost an average of $2 billion, and achieve approval rates of only ~15%. Despite the vast multi-modal data generated by years of clinical trials, AI experts have been hindered from fully utilizing this data due to the complexity of data collection and the need for deep medical knowledge to define meaningful prediction tasks. There is a need for standardized, AI-ready benchmark datasets that bridge the gap between clinical trial domain expertise and AI/ML expertise.

## Key Contributions

1. Identified **8 key AI-solvable clinical trial prediction tasks**: trial duration, patient dropout (event and rate), serious adverse event, mortality event, trial approval, trial failure reason identification, eligibility criteria design, and drug dose finding.
2. Curated **23 AI-ready datasets** covering these 8 tasks, with multi-modal input features from ClinicalTrials.gov, DrugBank, TrialTrove, and ICD-10 coding system.
3. Provided **5 modalities** of input data: drug molecule structure (SMILES), disease code (ICD-10), text (eligibility criteria, summaries), categorical/numerical features, and MeSH terms.
4. Developed a **multi-modal deep learning baseline** combining MPNN (for drug molecules), Bio-BERT (for text), MeSH Embedding (for MeSH terms), GRAM (for disease codes), and DANet (for tabular features).
5. Released **Python and R packages** (`trialbench`) for convenient dataset access and model development.
6. Validated datasets through comprehensive experiments demonstrating AI-readiness: the multi-modal baseline achieves F1 >= 0.7 on 11 out of 14 binary classification datasets.

## Methodology/Architecture

**Data sources:**
- **ClinicalTrials.gov:** Primary source; >480,000 trial records (as of Feb 2024) from 50 US states and 221 countries. XML records parsed into tabular format.
- **DrugBank:** Drug molecular structures (SMILES strings) and pharmaceutical properties.
- **TrialTrove:** Trial approval outcomes (from released/public subset).
- **ICD-10:** Disease code mapping via Clinical Table Search Service API.

**Task definitions and dataset sizes:**

| Task | AI Task Type | # Data Points | Input Modalities |
|------|-------------|---------------|-----------------|
| Trial duration prediction | Regression | 141,940 | All 5 modalities, 35 features |
| Patient dropout prediction | Classification + Regression | 62,058 | All 5 modalities, 38 features |
| Serious adverse event prediction | Classification | 31,306 | All 5 modalities, 38 features |
| Mortality event prediction | Classification | 31,306 | All 5 modalities, 38 features |
| Trial approval prediction | Classification | 43,202 | All 5 modalities, 35 features |
| Trial failure reason identification | 4-category Classification | 41,369 | All 5 modalities, 32 features |
| Eligibility criteria design | Generation | 136,443 | MeSH, SMILES, ICD-10, Texts, 25 features |
| Drug dose finding | 4-category Classification | 12,790 | SMILES, MeSH, 2 features |

**Multi-modal baseline architecture:**
- **Drug molecules:** Message Passing Neural Network (MPNN) -- processes 2D molecular graphs
- **Text features:** Bio-BERT -- pre-trained biomedical language model
- **MeSH terms:** Pretrained MeSH Embedding layer (node2vec algorithm)
- **Disease codes:** GRAM (Graph-based Attention Model) -- leverages ICD-10 hierarchy
- **Tabular features:** DANet (Deep Abstract Networks) -- modular architecture for categorical/numerical features
- **Fusion:** Concatenation of all modality embeddings (100-dim each) fed into MLP
- **Training:** Adam optimizer, lr=1e-3, batch size=64, max 20 epochs

**Data annotation:**
- Trial duration and dropout: computed directly from ClinicalTrials.gov dates and results
- Adverse events and mortality: extracted from ClinicalTrials.gov reported results
- Trial approval: from TrialTrove (HINT benchmark) plus ClinicalTrials.gov termination reasons
- Failure reasons: ChatGPT API used to classify "why stopped" text into 4 categories
- Drug dosing: ChatGPT API used to extract and categorize dosage from natural language
- Data split: 80/20 random partitioning (stratified for classification tasks)

## Datasets

**Scale and composition:**

| Statistic | Range |
|-----------|-------|
| Total trials (duration task) | 143,800 (largest dataset) |
| Total drugs | 40,800+ |
| Total diseases | 44,600+ |
| Medical devices | 21,100+ |
| Interventional studies | 77.3%--100% depending on task |
| Phase distribution | Majority Phase II (27.9%) |

**Data quality measures:**
- Only features available before trial start are included (preventing data leakage)
- Trials with duration >10 years removed as outliers
- Only completed trials used for eligibility criteria design
- Only Phase II trials for drug dose finding

**Top 20 sponsors** include GlaxoSmithKline (3,017 trials), NCI (2,826), Pfizer (2,346), MD Anderson (2,099), AstraZeneca (2,095), covering both pharma and academic institutions.

## Results

**Baseline validation results (selected):**

| Task | Phase | Key Metric | Value |
|------|-------|-----------|-------|
| Patient dropout (classification) | III | F1 | 0.9455 +/- 0.0029 |
| Patient dropout (regression) | I | R^2 | 0.6284 +/- 0.0290 |
| Adverse event prediction | III | F1 | 0.9297 +/- 0.0072 |
| Mortality event prediction | I | F1 | 0.7695 +/- 0.0300 |
| Trial approval prediction | III | F1 | 0.6724 +/- 0.0111 |
| Trial failure reason | II | F1 | 0.1499 +/- 0.0027 |
| Trial duration prediction | I | R^2 | 0.6514 +/- 0.0085 |
| Drug dose finding | II & III | F1 | 0.4938 +/- 0.0130 |
| Eligibility criteria design | All | Cosine sim. | 0.6988 |

**Key observations:**
- Multi-modal baseline achieves F1 >= 0.7 on 11 of 14 binary classification datasets, validating AI-readiness
- Trial failure reason identification remains very challenging (F1 ~0.15--0.20), suggesting room for advanced methods
- Drug dose finding is also challenging (F1 ~0.49)
- Phase III trials generally show better prediction performance than earlier phases for dropout and adverse events

## Limitations

- AI for clinical trials is a vast and fast-growing field; important tasks and datasets are yet to be included (acknowledged as an ongoing effort).
- Some labels were generated using ChatGPT (failure reasons, drug dosing), which may introduce annotation noise.
- Missing data is common -- some trials lack completion dates, outcomes, or drug information.
- Random data partitioning is used by default; temporal or location-based splits may better reflect real-world deployment.
- Only interventional trials with drug candidates are the primary focus; observational trials and non-drug interventions are less covered.
- TrialTrove data is from a released/public subset, which may not be fully representative.

## Relevance to CTRA

This paper is **directly relevant** to the CTRA project:

1. **Trial failure reason identification** is one of the 8 tasks, which includes "poor enrollment" as a failure category -- closely related to CTRA's "uninformativeness" concept, since uninformative protocols often fail due to enrollment issues, safety problems, or lack of efficacy.
2. **Trial approval prediction** (43,202 trials) provides a large-scale benchmark directly relevant to CTRA's goal of predicting whether a trial will produce useful results.
3. **Multi-modal feature engineering** approach (combining protocol text, drug molecules, disease codes, and tabular features) provides a template for CTRA's feature design.
4. **Dataset curation methodology** -- extracting from ClinicalTrials.gov XML, linking to DrugBank and ICD-10 -- is directly applicable to CTRA's data pipeline.
5. **Trial duration prediction** and **patient dropout prediction** are operational risk factors that relate to protocol uninformativeness.
6. **The baseline models** (especially Bio-BERT for text and DANet for tabular features) can be directly adopted or adapted for CTRA.
7. **The "why stopped" field** annotation using ChatGPT demonstrates a practical approach to labeling trial outcomes that CTRA could leverage.
8. **Eligibility criteria design** task provides insights into how overly restrictive or overly broad criteria contribute to trial issues.
